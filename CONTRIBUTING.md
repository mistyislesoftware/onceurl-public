# Contributions

External code contributions are not currently accepted.
This repository is a public source mirror. Changes originate in the canonical
engineering process and arrive as verified publication snapshots.
Direct commits and pull requests here are not authoritative.

Ordinary bug reports and product feedback are welcome through repository issues.
Do not include secrets, capability URLs, private data or vulnerability details.
Use the private reporting channel in `.github/SECURITY.md` for security reports.
Do not submit patches containing third-party code or confidential information.
